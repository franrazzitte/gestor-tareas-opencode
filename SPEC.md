**Contexto**

Se debe desarrollar una aplicación web sencilla para gestionar tareas personales. La aplicación permitirá al usuario organizar sus actividades pendientes desde una interfaz simple e intuitiva, pudiendo crear nuevas tareas, consultar las tareas existentes y actualizar su estado a medida que las complete. También podrá eliminar tareas que ya no necesite y filtrar la lista para visualizar las tareas según su estado.

**Requisitos funcionales**

La aplicación debe permitir:
1. Crear nuevas tareas.
2. Mostrar las tareas existentes.
3. Marcar una tarea como completada o volver a marcarla como pendiente.
4. Eliminar tareas.
5. Filtrar las tareas para mostrar todas, solamente las pendientes o solamente las completadas.
6. Mantener las tareas después de recargar la página.

**Restricciones técnicas**

La aplicación debe utilizar:
1. HTML para la estructura.
2. CSS para los estilos.
3. JavaScript vanilla para la lógica.
4. localStorage para guardar las tareas.
5. No se deben utilizar frameworks ni librerías externas y se deben mantener separados los archivos HTML, CSS y JavaScript.

**Criterios de aceptación**

La aplicación será aceptada si se puede:
1. Crear una tarea y verla en la lista.
2. Marcarla como completada.
3. Eliminar una tarea.
4. Utilizar correctamente los filtros.
5. Recargar la página y conservar las tareas.
6. Comprobar que se utilizó localStorage.
7. Comprobar que se respetaron las tecnologías y estructura indicadas.
